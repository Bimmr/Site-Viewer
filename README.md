## 🚀 How It Works

1. Click the extension and enter a website URL.  
2. Site-Viewer crawls the site to gather pages, files, and media.  
3. Browse the organized results or download combined assets for offline use.

## 🧠 Features

- **Site crawl & overview:** Pages, links, and assets in one place.
- **Export as single HTML:** Combine page + scripts + styles + images. 
- **Link checking:** View all found links and validate them.
- **Download media & files:** Save individual resources locally.

## 🔒 Privacy

✔ All processing happens locally in your browser.  
✔ No analytics or tracking collection.  
✔ No data is sent to external servers.
